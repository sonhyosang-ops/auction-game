# ⏳ 인생 경매 (Life Auction)

학생들과 함께하는 **가치 교육용 실시간 모의 경매 게임**입니다.
호스트(선생님) 화면 1대를 빔프로젝터로 띄우고, 학생들은 QR 코드를 스캔해 각자의 폰 브라우저로 참여합니다. 앱 설치도, 회원가입도 필요 없습니다.

## 왜 만들었는가

이 게임에서 학생들에게 주어지는 포인트는 돈이 아니라 **인생의 시간 80년**입니다.
입찰한다는 것은 곧 *한 번뿐인 인생의 시간을 그것에 투자한다*는 뜻입니다.

그래서 이 경매에는 특별한 규칙이 하나 있습니다.

> **어떤 물품이든 한 번 입찰하는 순간, 당신의 인생은 그 물품에 투자됩니다.
> 이후 다른 어떤 물품에도 입찰할 수 없습니다.**

경매는 두 부로 나뉘어 진행되지만, 게임이 끝날 때까지 학생들은 그 구분의 의미를 알지 못합니다.

| | 물품 | 의미 (게임 종료 후 공개) |
|---|---|---|
| **1부** | 명문대 · 의대 · 외모지상 · 인플루언서 · 억대연봉 | 있으면 좋아 보이지만, 얻어도 영원히 가질 수 없는 것 — **사라지는 것들** |
| **2부** | 평안 · 가족 · 친구 · 믿음 · 하나님 | 원하는 만큼 얻지 못한 것 같아도, 투자한 만큼 반드시 남는 것 — **없어지지 않는 것들** |

1부(허영)가 먼저 진행되기 때문에, 성급하게 인생을 써 버린 학생은 정작 소중한 것이 나왔을 때 아무것도 할 수 없습니다. 그 아쉬움 자체가 이 게임의 교육 장치입니다.

모든 경매가 끝나면 결과 화면에서 두 목록의 진짜 의미가 공개되고, 학생마다 자신의 선택에 대한 개인 메시지를 받습니다. 마무리로 호스트가 "📖 말씀" 버튼을 누르면 모든 화면에 디모데전서 6장 10절이 표시됩니다.

**핵심 질문:** *나는 무엇에 인생을 투자했는가? 그것은 사라지는 것이었는가, 남는 것이었는가?*

## 게임 규칙 요약

- 모든 참가자는 인생의 시간 **80년**을 받습니다 (설정에서 변경 가능)
- 물품마다 제한시간(기본 30초) 동안 경매가 진행되고, 종료 시 최고 입찰자가 낙찰받습니다
- 마감 5초 전에 입찰이 들어오면 자동으로 5초 연장됩니다 (막판 눈치싸움 방지)
- **한 물품에 입찰한 사람은 다른 물품에 입찰할 수 없습니다** (같은 물품 안에서 올려 부르는 것은 가능)
- 낙찰자만 시간을 지불하며, 낙찰받지 못해도 그 물품에 인생을 건 것으로 기록됩니다

## 사용법 (수업 진행 순서)

### 준비

1. 호스트(선생님) 컴퓨터에서 `https://<배포주소>/host` 를 열고 빔프로젝터에 투사합니다
2. 오른쪽 **⚙️ 설정**을 클릭해 열고 → **설정 적용**을 누릅니다 (물품·시간 등록)
   - ⚠️ 설정 패널에는 허영/가치 분류가 보이므로, 투사 중에는 닫아 두세요
3. 화면의 QR 코드를 학생들이 폰 카메라로 스캔 → 이름 입력 → 입장
4. 오른쪽 참가자 목록에서 전원 입장을 확인합니다

### 진행

5. **🎺 경매 시작 알림음** 버튼으로 장내를 집중시킵니다 (20초 후 자동 정지)
6. **▶ 다음 물품 경매 시작**을 누르면 물품 이미지·시작가와 함께 카운트다운이 시작됩니다
7. 학생들은 폰에서 `+1년 / +5년 / +10년` 버튼으로 입찰합니다
8. 필요하면 **⏹ 지금 종료**로 조기에 낙찰/유찰을 확정할 수 있습니다
9. 물품 사이 대기 화면에는 다음 물품이 미리 표시됩니다 (1부 마지막 물품 진행 중에는 2부가 미리 보이지 않습니다)

### 마무리

10. 모든 물품이 끝나면 결과 화면이 자동으로 열립니다 — 사라지는 것들 / 없어지지 않는 것들
11. **📖 말씀** 버튼으로 디모데전서 6:10을 전체 화면에 띄우고 이야기를 나눕니다
12. 다시 하려면 설정 패널의 **🔄 게임 전체 초기화** 후 설정을 다시 적용합니다

## 커스터마이징

- **물품 목록**: 설정 패널에서 한 줄에 하나씩 `이름,시작가,허영|가치` 형식으로 수정
- **물품 이미지**: `public/items/<물품명>.png` 파일을 넣으면 자동으로 표시됩니다
- **알림음**: `public/sounds/start.m4a` 파일을 교체하면 됩니다
- **시작 시간·제한시간**: 설정 패널에서 변경

## 실행 방법

### 로컬 실행

```bash
npm install
npm start
# 호스트: http://localhost:3000/host  /  학생: http://localhost:3000
```

같은 Wi-Fi라면 QR에 표시된 주소로 학생 폰이 바로 접속됩니다.

### Render 배포

저장소에 `render.yaml` 블루프린트가 포함되어 있습니다. Render에서 New → Blueprint로 이 저장소를 연결하면 무료 플랜 Node 웹 서비스가 자동 구성됩니다. (수동 생성 시: Build `npm install`, Start `node server.js`)

> 무료 플랜은 15분간 접속이 없으면 잠들어 첫 접속이 느립니다. 수업 5분 전에 미리 열어 두세요.
> 게임 상태는 서버 메모리에만 저장되므로 서버가 재시작되면 초기화됩니다 (한 수업 세션 안에서는 문제없습니다).

## 기술 구성

- **서버**: Node.js + Express + Socket.IO — 파일 하나(`server.js`), 상태는 인메모리
- **클라이언트**: 순수 HTML/JS 2장 (`host.html`, `index.html`) — 빌드 과정 없음
- **QR 코드**: 서버에서 생성 (`qrcode` 패키지, 외부 CDN 불필요)
- 동시 접속 20~30명 규모의 교실 수업에 맞춰 단순하게 설계되었습니다
